# KitchenCare (Hekki)

This is a premium AI-powered kitchen management app designed for Employers and Helpers.

## ✨ Features Added

### 🎨 Premium UI & GSAP Animations
- **Interactive Doll (Launch Page)**: A 3D-parallax GSAP animation that follows the cursor and responds with smiles/squints.
- **GSAP Bottom Navigation**: A MacOS-style dock effect for the main navigation bar.
- **Modern Design**: Glassmorphism effects, custom gradients, and a sleek, responsive layout.

### 🔔 Smart Notification System
- **Dual-Level Badges**: Real-time notification badges on the main Chat icon and internal tabs (Chat/Settings).
- **Premium Aesthetics**: High-contrast red badges with white borders and shadows, featuring a "pop" bounce animation.
- **Unread Logic**: Intelligent filtering of unread messages and pending invitations.

### 🤖 AI-Powered Workflow
- **Recipe Planning**: AI-driven recipe selection and health profile adjustments.
- **Real-time Chat**: Live chat with automatic translation and audio recording support.

## 🚀 Getting Started

**Prerequisites:** Node.js

1. **Install dependencies:**
   `npm install`
2. **Setup API Key:**
   Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key.
3. **Run the app:**
   `npm run dev`
